42,849 Stars in 25 Days: Craft Anything Wants to Understand Any Software — Then Rebuild It

Nov 25, 2026 by Awesome Intelligence Open Source AI Agents Rust

AI writing code stopped being news a while ago. AI reading other people's software — figuring out how a finished product is put together, then building its own version of it — is a newer and stranger trick. That is exactly what Craft Anything, an open-source project from the Storytold team, sets out to do. It was published on October 31, and 25 days later it sits at 42,849 GitHub stars and 8,468 forks. Numbers like that usually mean a project has touched a nerve. This one has: everyone has, at some point, seen a website or a tiny game and thought, "I wish I could make one of those" — then bounced off the weeks of reverse-engineering that wish normally requires.

  • Repository: github.com/storytold/craft-anything
  • Stars / forks: 42,849 / 8,468 (as of Nov 25, 2026)
  • Latest release: v0.6.1
  • Written in: Rust · License: Apache-2.0
  • Website: getartcraft.com

Point at a target, press Start

The basic flow is disarmingly simple. Open the app, choose whether your target is a website, an application, or a game, give it an address, pick clean-room or deep mode, describe in one sentence what you want, and press Start. From there the work moves through four stages — research, build, inspect, ready — and the project page narrates each one in plain language: what the agent is doing, which checks passed, and how similar each page of the rebuild is to the original. Whenever a decision actually matters, the run pauses and asks you, with a question card or an approval card. Nothing outside the stated rules happens without your sign-off.

If you only want to look around rather than build, there is a "look inside only" entry point: open a target, ask questions about it, and build nothing. That one requires deep mode, for reasons that will become obvious in a moment.

This "ask first, act second" design is the first thing that sets Craft Anything apart from the usual agent demo. The agent is not off freelancing; it works a checklist, in the open, with a human in the loop.

Research with receipts: 314 tools

The research stage is powered by a reverse-engineering engine written entirely in Rust, shipping 314 tools that cover native binaries, .NET, Java, Android, Apple platforms, Electron, websites, firmware, packet captures, databases, and game files. Its decoders, disassemblers, and decompilers are built in — they work without installing any external programs. For games, it handles the mainstream engines: Unity, Unreal, and Godot. Generating images or 3D models is opt-in and runs on your own fal.ai key.

What matters more than the tool count is the discipline around it. Every conclusion the engine reaches is recorded with its evidence in a ledger you can audit, and the inspection checklist spells out exactly where the rebuild still diverges from the original — down to a similarity score per page. Compare that with the standard "AI glances at a screenshot and starts typing" approach: here, the understanding phase produces artifacts you can check before a single line of your version exists.

Your agent does the building — and gets graded

Craft Anything does not bring its own model subscription to the build stage. It requires a coding agent already installed and logged in on your machine — Claude Code is the preferred one — and it runs your unmodified copy of that agent, under your login. The project is explicit that it never sees or touches your account. You describe the target ("recreate this game's mechanics in Rust"), and the agent scaffolds a fresh project in the language, framework, or engine you specify. The README's Snake clone was produced exactly this way; when the run finishes, the project page even has a "play the game" button so you can try the result immediately.

Then comes the part most "AI rebuilds X" demos skip: verification. Every build is compared against the original — web pages at three viewport widths, games through their own self-checks, apps by observing them run — and the mismatches are listed so the loop can iterate until the rebuild converges. "Looks about right" is not the standard; measured similarity is. That said, convergence means similar, not identical, and anything headed for production still deserves your own review pass.

Clean room by default, deep mode when you say so

The default mode is a strict clean room. The engine refuses to read anything internal about the original — no source code, no files, no page source. It works only from what an ordinary visitor could observe: screenshots, visible text, and measured layout, colors, fonts, and spacing. Any tool that would peek inside is rejected, and the app tells you how to enable deep mode if that is really what you want. Deep mode — toggled in the title bar or settings, via settings_set deep_mode true, or per-run with the CLI's --deep flag — unlocks the full toolset, lets the built-in engine read program code and files, and will use Ghidra if you have it installed.

The README also draws its ethical line in plain sight: use it on software you own or are permitted to inspect; never to defeat DRM, logins, or anti-cheat systems; and before copying a logo, photo, or text, make sure you own it or have permission. For a tool in this category, stating the boundary that clearly is a feature, not fine print.

No UI required: CLI and MCP

Every one of the 314 tools is both a CLI subcommand and an MCP tool, so any agent can drive the same engine the app uses. A full rebuild from the terminal is one line:

craft-anything-cli rebuild https://example.com "Recreate this website"

craft-anything-cli commands lists the whole toolset, craft-anything-cli mcp hands the tools to any MCP client, and craft-anything-cli doctor checks your install, coding agent, and engine before you start. New projects land in a Documents/Craft Anything folder by default, each with a craft.json, plus capture/, app/, and checks/ directories holding the evidence and comparison results. There is even a WebAssembly build that runs the engine in a browser.

The honest part: it is early alpha

Credit where due — the project is upfront about its rough edges. Some features have so far only been exercised with stand-in tests; building through API keys or coding agents other than the primary path has not yet been verified on real machines; and the behavior checks for apps and games are still being filled out. You will need a logged-in coding agent on your machine, and building from source requires Rust 1.97 or newer. If you would rather skip compiling, the Releases page has installers for Windows, macOS, Linux, and FreeBSD — the macOS build is signed and notarized.

Who should try it

Indie developers get a way to learn from software they admire and to validate an idea in days instead of weeks; teams get a serious instrument for studying how a competitor's product is assembled before building their own take. Craft Anything is also just the first piece of a larger Craft App Suite from the same team — PhotoCraft for image editing, VectorCraft for vectors, FilmCraft for video, LightCraft for photo libraries — all built on the same "understand it, then craft it" idea.

The shift it represents is real: AI making software is moving from "help me write this code" to "understand this thing, then make me one." Whether you use it to clone a landing page, resurrect a game mechanic, or simply find out how a piece of software ticks, it is one of the most interesting open-source releases of the season — and at 42,849 stars in 25 days, a lot of developers clearly agree.
